# Default

Default is the control theme: the one a well-built desktop application would ship if it
had no interest in being a place. Near-neutral greys, a steel accent, system UI type, and
light/dark variants that follow `prefers-color-scheme`. There is no background pass and no
post-process — the grid is the picture. Motion is crisp, short, and without bounce, the way
a native window moves. Sound is a handful of UI clicks and nothing else: no ambient bed, no
birth ticks, no texture. That restraint is the point. Default is the performance reference
and the accessibility reference. It must always be the fastest of the six, and it is the
only theme that is fully itself at quality 0, because quality 0 is all it ever was.
