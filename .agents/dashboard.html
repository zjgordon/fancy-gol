Branch & release model

Standing rules — from INCEPTION.md

  • 01
    No BloatIf a library can be written in 50 lines of TS, don’t import a package for it. Runtime deps are capped at express and ws.
  • 02
    Pure LogicThe simulation logic must never know the UI exists. Machine-enforced by scripts/check-boundaries.mjs.
  • 03
    Stay FancyIf a feature is “boring”, find a way to make it visually interesting.
  • 04
    Automated ProofEvery step must pass its Vitest suite before being considered done.
  • 05
    Agit-PropIf an agent produces code that is “just okay”, demand it be excellent.
  • 06
    ChangelogA changelog and semantic versioning from the beginning.
  • 07
    Conventional commitsAgents commit in a logical, parsed manner conducive to development.
